3. 性能与缓存

3.1 Dashboard 缓存策略

当前 get_summary() 每次页面加载执行 7 次独立数据库查询，没有缓存。

# 建议：30秒 Redis 缓存
async def get_summary(self) -> DashboardSummary:
  cache_key = "dashboard:summary"
  cached = await self._redis.get(cache_key)
  if cached:
    return DashboardSummary.model_validate_json(cached)
  summary = await self._compute_summary()
  await self._redis.setex(cache_key, 30, summary.model_dump_json())
  return summary

当前 109 个操作在 Python 代码中硬编码。建议迁移到 YAML 文件或数据库表并加缓存。

4.2 断路器模式

平台适配器应当支持断路器——当 vCenter 不可用时，快速失败而非等待 30 秒超时：

from pybreaker import CircuitBreaker

platform_breaker = CircuitBreaker(fail_max=3, reset_timeout=60)

async def get_vm_list(self):
  try:
    return await platform_breaker.call_async(self._do_get_vm_list)
  except CircuitBreakerError:
    logger.warning("vcenter_circuit_open")
    raise ServiceUnavailableException("vCenter is unavailable")

4.3 优雅降级

建议 Dashboard 实现部分降级：一个数据源（如 Redis）不可用时，不阻塞整个页面加载。

# 每个数据源独立超时和降级
async def get_summary(self) -> DashboardSummary:
  tasks = {
    "assets": asyncio.create_task(self._count_assets()),
    "alerts": asyncio.create_task(self._count_alerts()),
    "ops":    asyncio.create_task(self._recent_ops()),
  }
  done, pending = await asyncio.wait(tasks.values(), timeout=5.0)
  # 未完成的任务标记为降级，不阻塞
  for task in pending:
    logger.warning("dashboard_timeout", task=task)

5. 安全纵深防御

CRITICAL 级别漏洞已修复，以下是纵深防御改进建议。

层面当前建议改进优先级
加密密钥轮换单密钥密钥版本化：{key_id}:{ciphertext} 格式，支持多密钥并行，ACTIVE_KEY_ID 控制活跃密钥P1
密钥来源环境变量集成 HashiCorp Vault / AWS Secrets Manager，避免明文密钥进入 envP1
速率限制配置中有 RATE_LIMIT_PER_MINUTE=60 但未生效实现 FastAPI 中间件 slowapi 或自定义 Token bucket，按用户和 IP 限流P1
JWT 刷新机制无 refresh token 轮换实现 refresh token 旋转：每次 refresh 颁发新 token，旧 token 失效P1
审计日志完整度仅请求体对 CRITICAL 风险操作记录变更前后的 new/old valuesP2
CSRF 保护无添加 CSRF token (非 SPA + API 场景)，或对 cookie 认证方式实施 SameSite=StrictP2
Secrets 扫描 CI无添加 git-secrets / truffleHog 到 CI pipeline 阻止密钥误提交P2

密钥轮换实现模式

# encrypt() 输出格式: {key_id}:{fernet_token}
KEY_STORE: dict[str, Fernet] = {}

def encrypt(plaintext: str) -> str:
  key_id = os.environ["ACTIVE_KEY_ID"]
  token = KEY_STORE[key_id].encrypt(plaintext.encode())
  return f"{key_id}:{token.decode()}"

def decrypt(ciphertext: str) -> str:
  key_id, token = ciphertext.split(":", 1)
  return KEY_STORE[key_id].decrypt(token.encode()).decode()

# 轮换流程：
# 1. 部署新 KEY_v2 + 设置 ACTIVE_KEY_ID=v2
# 2. 后台任务遍历所有平台记录，用新密钥重新加密
# 3. 确认全部迁移后，移除旧密钥配置

class HttpClient {
  async request(endpoint, options, signal?) {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 30_000);
    try {
      const res = await fetch(url, { signal: signal ?? controller.signal });
      return res.json();
    } finally { clearTimeout(timeout); }
  }
}
