4. 新增发现 — 第三次审查捕捉到的问题

4.1 操作执行器：超时子进程未正确终止（新发现）

问题： _execute_real() 中 proc 变量的作用域问题 — 只有在 create_subprocess_exec 成功后 proc 才存在。
# operation_executor.py L289-308 — 当前代码
cmd_args = cmd_map.get(operation_id)
if cmd_args:
  try:
    proc = await asyncio.create_subprocess_exec(*cmd_args, ...) # ← 赋值
    stdout, stderr = await asyncio.wait_for(proc.communicate(), timeout=30)
    return {...}
  except asyncio.TimeoutError:
    proc.kill() # ← 作用域 OK（因为 create_subprocess_exec 先成功）
    await proc.wait()
  except Exception: # ← 缺失！create_subprocess_exec 本身可能抛出异常
    # proc 从未赋值，但 Exception 未被捕获
P2影响：创建子进程失败时，异常向上传播但 proc 未定义
建议改进：
proc = None
try:
  proc = await asyncio.create_subprocess_exec(...)
  stdout, stderr = await asyncio.wait_for(proc.communicate(), timeout=30)
  return {...}
except asyncio.TimeoutError:
  if proc: # 安全守卫
    proc.kill(); await proc.wait()
  raise OperationFailedException(...)
finally:
  if proc and proc.returncode is None:
    proc.kill(); await proc.wait() # 保证清理
